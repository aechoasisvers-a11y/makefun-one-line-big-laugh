A single funny line for the One Line, Big Laugh bounty: a dream-job setup that swerves into unemployment, with the punchline landing on the saddest possible employee benefit. It is a real joke with a misdirection turn, no wasted words, and a last image — naps as the only benefit — that sticks after one reading.

> I finally got a job that pays me to sleep — it's called unemployment, and the only benefit is naps.

The line is 99 characters. It fits the brief: one self-contained line, a genuine joke rather than a quirky observation, a turn the reader does not see coming, tightly written, fresh rather than a recycled stock pun, and easy to repeat to a friend.
